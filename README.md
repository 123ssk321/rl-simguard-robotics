# SimGuard Robotics

Local simulated robot policy regression and perturbation evaluation with reproducible failure reports.

**Status: queued planning candidate. Implementation has not started.** These delivery plans do not demonstrate a working product. Publication is separate from the first functional public alpha at relative month 4, following explicit activation.

## Intended workflow

Regression evaluation for a single low-dimensional simulated robot control task.

Simulation-only policy evaluation. No physical robot operation, real-world safety qualification or broad simulator platform.

## Constraints

16 hours/week shared across the portfolio; one active project after explicit selection. Local CPU-first workflow, optional 4GB GPU, no paid data/cloud. Public permitted data or automatically generated scenarios; no manual dataset construction. Conferences provide technical inspiration only.

The plan contains 276 task hours and 120 reserve hours (396 total). Each task is a bounded proposal, not a promise that its outcome is achievable unchanged. Unresolved rights, failed feasibility checks or absent product value can result in narrowing or stopping.
